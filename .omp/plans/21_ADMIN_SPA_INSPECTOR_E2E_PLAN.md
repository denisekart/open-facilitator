## Locked decisions
1. **Package:** new pnpm member `src/facilitator/ui` (name `@ofac/ui`, private, `"type":"module"`), vite + Svelte 5 (runes) + Tailwind + shadcn/svelte, builds into `src/facilitator/wwwroot/` (gitignored except `.gitkeep`); `svelte-check` as its `typecheck` script (auto-covered by `pnpm -r --if-present typecheck`); `.svelte` files excluded from root eslint (plugin-free: `svelte-check` + `vite build` are the gate), TS in the package stays eslint-covered.
2. **Auth:** in-browser OIDC authorization-code + PKCE (S256) against public client `facilitator-api` using the **`oidc-client-ts`** library (add to the pnpm catalog) — no hand-rolled flow, no server session. Access token in memory + `sessionStorage` user, silent renew (`prompt=none` iframe); on refresh failure → re-login. `Authorization: Bearer` on every `/api/*` fetch.
3. **Runtime bootstrap config:** one new **anonymous non-`/api` route** `GET /ui-config` returning `{ "oidcAuthority", "oidcClientId", "aspireDashboardUrl" }` from a new `ui:` config section (dev: `http://localhost:8480/realms/facilitator`, `facilitator-api`, `""`; slim `reference/config/facilitator.json`: `http://id.localhost:8080/realms/facilitator`, `facilitator-api`, `http://localhost:18888`). Empty `aspireDashboardUrl` hides trace egress. It is not part of the frozen `/api/admin` surface (one-line rationale in the route doc-comment: SPA bootstrap, intentionally outside the role gate).
4. **Serving:** `app.UseDefaultFiles(); app.UseStaticFiles(); app.MapFallbackToFile("index.html");` appended to the `Program.cs` pipeline (after the gate — non-`/api` paths bypass it anyway). Cache-busting via vite hashed filenames; `index.html` served no-cache is not required for acceptance.
5. **Image:** `src/facilitator/Dockerfile` gains a `node:22` (per `versions.env`/Node 22 LTS engines) build stage: corepack pnpm, `pnpm install --frozen-lockfile --filter @ofac/ui`, copy the ui + root config files, `pnpm --filter @ofac/ui build`, then `COPY --from=ui /ui/wwwroot /app/wwwroot` into the aspnet runtime stage. The published kernel and the compose image carry the SPA — one deployable (§17).
6. **Inspector-first UI:** one screen — search bar (top), health strip (summary + metrics, bounded polling: summary every 15 s, metrics every 60 s, no websockets), inspector pane (typed result sections → contextual detail + activity panel + approvals/manifests/artifact panels + links/deliveries views), edit affordances ONLY: approval respond, dead-letter replay (confirm + typed reason shown via `X-Change-Reason`), manifest re-mark, config PATCH forms per resource. RBAC: mutations hidden when the token lacks `framework-admin`/`kernel-operator` (decode the JWT client-side); reads render for anyone who can auth.
7. **E2E:** a new **`tests/Facilitator.E2E`** xUnit + Microsoft.Playwright project (registered in `OpenFacilitator.slnx`, `<PwBrowser>`/`playwright install chromium` in CI) against a **spawned real-Kestrel kernel** (`WebApplicationFactory<Program>` subclass forcing Kestrel on a free port), Testcontainers Postgres + the existing `KeycloakFixture` (8480 — dev config's authority already matches), served `wwwroot` = the vite build output. Runs at the **PR tier**. The live-slim browser walkthrough stays the manual acceptance step (as Plan 20's step 8 was).
8. **Stale-gateway display:** offline rows show `lastHeartbeat`/epoch + affected assignments (view-model already shaped); badge copy "offline (last seen …)" — Plan 20 collapsed stale into offline.
9. **No API growth:** no client-side aggregation to paper over DTO gaps; a real gap re-opens 20, not this plan (exception: the bootstrap `/ui-config`, decision 3).
